# MomAI Docs

**MomAI Docs** è uno studio di creazione basato sulle tue fonti per realizzare documenti, tesi, lettere ufficiali, carta intestata, presentazioni PowerPoint, podcast a due voci, video esplicativi, fogli di calcolo e mappe mentali.

## Funzionalità

- **Progetti isolati**: organizza fonti, cronologia, brand kit e artefatti per singolo progetto.
- **Fonti verificate**: aggiungi PDF, DOCX, PPTX, XLSX, testo, immagini, link web, YouTube o ricerca curata.
- **Modelli professionali**: scegli strumento e modello con anteprime reali.
- **Carta intestata intatta**: compila file `.docx` e `.pdf` mantenendo intestazioni, piè di pagina e filigrane.
- **Studio Audio e Video**: genera podcast e video esplicativi con voce narrante e sottotitoli.

## Permessi

- **Rete**: recuperare pagine web, trascrizioni YouTube e suggerimenti di fonti.
- **File (Lettura / Scrittura)**: importare fonti ed esportare i file generati.
- **Messaggi di chat**: creare e rifinire direttamente dalla chat di MomAI o dallo studio.
