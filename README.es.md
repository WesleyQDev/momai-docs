# MomAI Docs

**MomAI Docs** es un estudio de creación basado en tus fuentes para generar documentos, trabajos académicos, oficios, hojas membretadas, presentaciones PowerPoint, podcasts de dos voces, videos explicativos, hojas de cálculo y mapas mentales.

## Qué hace

- **Proyectos aislados**: organiza fuentes, historial, kit de marca y artefactos por proyecto.
- **Fuentes como base de verdad**: agrega PDF, DOCX, PPTX, XLSX, texto, imágenes, enlaces web, YouTube o búsqueda curada.
- **Plantillas profesionales**: elige herramienta y plantilla con vistas previas reales.
- **Hoja membretada intacta**: rellena archivos `.docx` y `.pdf` conservando encabezados, pies de página y marcas de agua.
- **Estudio de Audio y Video**: genera podcasts y videos explicativos con narración y subtítulos.
- **Refinamiento conversacional**: pide ajustes como "hazlo más formal" o "cambia la diapositiva 3", compara versiones y exporta archivos editables.

## Permisos

- **Red**: obtener páginas web, transcripciones de YouTube y sugerencias curadas.
- **Archivos (Lectura/Escritura)**: importar fuentes y exportar los archivos generados.
- **Mensajes de chat**: usar el estudio desde el chat principal de MomAI o desde la extensión.
