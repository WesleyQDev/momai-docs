# MomAI Docs

**MomAI Docs** is a source-grounded creation studio for documents, academic papers, official letters, letterhead fills, PowerPoint presentations, two-host podcasts, explainer videos, spreadsheets, mind maps, and study materials.

## What it does

- **Project workspaces**: keep sources, chat history, brand kits, and generated artifacts isolated per project.
- **Sources as the single source of truth**: add PDFs, Word documents, presentations, spreadsheets, text/Markdown, images, audio/video, web links, YouTube videos, or use curated web discovery.
- **Pre-built professional templates**: pick a tool and template (Official Letters, Handbooks, ABNT Papers, Letterhead Fill, PowerPoint, Podcast, Explainer Video, Executive Reports, Flashcards/Quiz, Mind Maps, XLSX) with real previews.
- **Preserved letterhead filling**: fill existing `.docx` and `.pdf` letterheads without recreating or distorting headers, footers, or watermarks.
- **Audio & Video Studio**: generate multi-voice podcasts and deterministic SVG explainer videos with narration and subtitles.
- **Conversational refinement**: edit any section or slide by asking in plain language, compare versions, and export ready-to-use files.

## Permissions

- **Network**: fetch web/YouTube sources and curated search suggestions.
- **Files (Read / Write)**: import source files, letterhead templates, and export generated documents and media.
- **Chat messages**: interact with your project directly from the main MomAI chat or the extension workspace.
