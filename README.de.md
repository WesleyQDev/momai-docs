# MomAI Docs

**MomAI Docs** ist ein quellenbasiertes Studio zum Erstellen von Dokumenten, wissenschaftlichen Arbeiten, offiziellen Briefen, Briefbögen, PowerPoint-Präsentationen, Podcasts, Erklärvideos, Tabellen und Mindmaps.

## Funktionen

- **Isolierte Projekte**: verwalten Sie Quellen, Verlauf, Marken-Kit und Artefakte getrennt pro Projekt.
- **Quellen als Wahrheitsbasis**: PDF, DOCX, PPTX, XLSX, Text, Bilder, Weblinks, YouTube oder kuratierte Suche.
- **Professionelle Vorlagen**: wählen Sie Werkzeug und Vorlage mit echter Vorschau.
- **Unveränderter Briefkopf**: befüllen Sie `.docx`- und `.pdf`-Briefbögen ohne Kopf- oder Fußzeilen neu zu bauen.
- **Audio- & Videostudio**: erzeugen Sie zweistimmige Podcasts und SVG-Erklärvideos mit Untertiteln.
- **Konversationelle Verfeinerung**: Bitten Sie um Anpassungen wie „formeller formulieren“ oder „Folie 3 austauschen“, vergleichen Sie Versionen und exportieren Sie bearbeitbare Dateien.

## Berechtigungen

- **Netzwerk**: Webseiten, YouTube-Transkripte und Quellenvorschläge abrufen.
- **Dateien (Lesen/Schreiben)**: Quellen importieren und fertige Dateien exportieren.
- **Chat-Nachrichten**: Steuerung über den MomAI-Chat oder direkt im Studio.
